# خطة إضافة الميزات الاحترافية (مرجع الصور)

## ما استخرجته من الصور
1. **PharmaAI** — فاحص أعراض تفاعلي (محادثة + صورة) يقترح دواء + جرعة + آثار جانبية + بديل طبيعي + مستوى خطورة، وموسوعة أدوية بالبحث، وسجل للمحادثات.
2. **صيدلي الذكاء الاصطناعي (DrGuide)** — بطاقة دواء موحّدة بـ **19 نقطة بيانات**: الاسم، الفئة، دواعي الاستعمال، الجرعة، موانع الاستعمال، التحذيرات، التفاعلات، التكلفة، الفئات العمرية، الفشل الكبدي، الفشل الكلوي، كبار السن، الأطفال، الحمل، الرضاعة، التخزين، الأشكال الصيدلانية، الجرعة الزائدة، إرشادات المريض. + أدوات: فاحص التفاعلات، فاحص الآثار الجانبية، مُعرّف الأقراص، أدوات الحمل، BMI.
3. **Medcytix** — أكاديمية مصطلحات طبية: مسارات تعلّم، تصنيفات (تشريح، فسيولوجيا، أدوية…)، صفحة مصطلح فيها تفكيك الكلمة (جذر/سابقة/لاحقة)، مثال سريري، ملاحظة تاريخية، مصطلحات مرتبطة، نطق صوتي، ثنائي اللغة.
4. **Flashcards** — بطاقات مراجعة قابلة للقلب/السحب + اختبار + مفضلة + تصنيف حسب المستوى.

## رأيي في البنية (التوصية)
**لا نصنع أقسامًا منفصلة كثيرة.** ندمج في **قسمين رئيسيين موجودين + قسم جديد واحد**:

| الميزة | أين توضع |
|---|---|
| بطاقة الدواء 19 نقطة + أدوات صيدلانية | داخل **قسم الأدوية** (توسيع) |
| فاحص الأعراض التفاعلي | داخل **المساعد الذكي (AiFab)** كوضع جديد |
| المصطلحات + المسارات + البطاقات + الاختبارات | **قسم جديد: «الأكاديمية»** (تبويب سادس) يستوعب أيضًا اختبارات التمريض الحالية |

الربط المتبادل: كل مصطلح → دواء مرتبط → بروتوكول تمريض/إسعاف مرتبط، عبر مُعرّفات مشتركة.

## المهام (كل مهمة = تنفيذ ثم استئذان)

**م1 — بنية بيانات الدواء الموحدة**
نموذج `DrugMonograph` بـ19 حقلاً + مصادر موثوقة (FDA DailyMed, BNF/NICE, WHO EML, Medscape, MedlinePlus بالعربية، الهيئة السعودية SFDA). بذرة ٦٠ دواءً شائعًا عربيًا/عالميًا.

**م2 — واجهة بطاقة الدواء**
صفحة دواء بأقسام قابلة للطي، شارات تحذير (حمل/كلى/كبد)، نسخ/طباعة، بحث عربي+إنجليزي.

**م3 — الأدوات الصيدلانية**
فاحص التفاعلات (اختيار عدة أدوية → شدة التفاعل)، فاحص الآثار الجانبية، حاسبة الجرعة للأطفال، BMI/مساحة الجسم، أدوات الحمل (فئات A–X).

**م4 — فاحص الأعراض التفاعلي**
وضع «فحص الأعراض» في المساعد الذكي: سؤال/جواب موجّه + دعم الصورة، مخرجات منظمة (سبب محتمل، خطورة، دواء مقترح، بديل طبيعي، متى تراجع الطبيب) + إخلاء مسؤولية إلزامي + سجل محلي.

**م5 — قسم الأكاديمية (الهيكل)**
تبويب جديد + شاشة رئيسية: «تابع التعلم»، مسارات، تصنيفات، بحث في القاموس، شريط تقدّم محلي.

**م6 — قاموس المصطلحات الطبية**
٤٠٠+ مصطلح ثنائي اللغة مع تفكيك الكلمة، مثال سريري، ملاحظة تاريخية عند وجودها، مصطلحات مرتبطة، نطق TTS (نستخدم `useSpeak` الموجود).

**م7 — البطاقات التعليمية والاختبارات**
بطاقات قابلة للقلب مع سحب، مفضلة، تكرار متباعد بسيط (SM-2 مبسّط)، اختبار MCQ يعيد استخدام محرك `QuizPanel` الحالي + شهادة.

**م8 — الربط والصقل**
روابط متبادلة (مصطلح ↔ دواء ↔ بروتوكول ↔ إسعاف)، وضع ليلي، RTL، أداء (lazy)، وصولية، مراجعة نهائية.

## ملاحظات تقنية
- كل تقدّم التعلّم والسجل الطبي يبقى **محليًا مشفّرًا Base64** (`localHealthStore`) التزامًا بقاعدة الخصوصية المعتمدة.
- بيانات الأدوية/المصطلحات ثابتة (JSON داخل التطبيق) = يعمل دون إنترنت، والذكاء الاصطناعي للإثراء فقط.
- المصادر تُعرض أسفل كل بطاقة (شفافية طبية).
